# Mac SSH Config — Connecting via Cloudflare Tunnel

After the tunnel is running on the VM, do this once on your Mac to connect via SSH.

---

## 1) Install cloudflared on Mac

```bash
brew install cloudflared
```

Verify:
```bash
which cloudflared
# e.g. /usr/local/opt/cloudflared/bin/cloudflared
```

---

## 2) Add SSH config entry

```bash
nano ~/.ssh/config
```

Add this block (use your actual SSH domain and username):

```
Host ssh.hermes-dev.arshware.com
  User malik
  ProxyCommand /usr/local/opt/cloudflared/bin/cloudflared access ssh --hostname %h
```

> Use the actual path from `which cloudflared` — do not use `$(which cloudflared)`, SSH config does not evaluate shell expressions.

---

## 3) Connect

```bash
ssh malik@ssh.hermes-dev.arshware.com
```

---

## Multiple VMs

Add a separate block per VM:

```
Host ssh.hermes-dev.arshware.com
  User malik
  ProxyCommand /usr/local/opt/cloudflared/bin/cloudflared access ssh --hostname %h

Host ssh.hermes-prod.arshware.com
  User malik
  ProxyCommand /usr/local/opt/cloudflared/bin/cloudflared access ssh --hostname %h
```

---

## Troubleshooting

**Operation timed out** — ProxyCommand missing or cloudflared not in PATH.

**Bad configuration option** — typo in `~/.ssh/config`. Check `Host` is spelled correctly with no leading characters.

**Permission denied** — SSH key not on the VM. Copy it:
```bash
ssh-copy-id -i ~/.ssh/id_rsa.pub malik@<vm-local-ip>
```

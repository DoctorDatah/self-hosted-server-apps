# Cloudflare Tunnel — Where to Find Your Credentials

The install script prompts for 3 values. Here's where to find each one.

---

## 1) Cloudflare Account ID

- Cloudflare Dashboard → right sidebar on any page
- Or: **Zero Trust** → **Settings** → **General** → **Account ID**

---

## 2) Cloudflare API Token

Create a token with tunnel + DNS permissions:

1. Cloudflare Dashboard → **My Profile** → **API Tokens** → **Create Token**
2. Choose **Create Custom Token**
3. Add these permissions:
   - **Account** → Cloudflare Tunnel → **Edit**
   - **Zone** → DNS → **Edit**
4. Scope to your account and the zone for your domain (e.g. `arshware.com`)
5. Create and copy the token — shown once only

> Zone ID is **not needed** — the script looks it up automatically from your SSH domain.

---

## 3) SSH Domain

The subdomain you want SSH routed through, e.g.:
- `ssh.hermes-dev.arshware.com`
- `ssh.hermes-prod.arshware.com`

Use dots and hyphens only — no underscores (invalid in DNS).

---

## Run

```bash
sudo -E bash cloudflare_install_and_setup.sh
```

The script will:
- Look up your Zone ID from the domain automatically
- Create the tunnel and DNS CNAME record
- Start cloudflared via docker compose

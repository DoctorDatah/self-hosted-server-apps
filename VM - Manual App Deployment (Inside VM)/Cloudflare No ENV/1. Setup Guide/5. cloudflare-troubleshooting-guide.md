# Cloudflare Tunnel — Troubleshooting

---

## 1) Check container status

```bash
docker ps | grep cloudflared
docker logs --tail 100 cloudflared-cloudflared-1
```

Or tail live:
```bash
docker compose -f cloudflare_install_and_setup.sh logs -f
```

If the container isn't running, re-run the install script:
```bash
sudo -E bash cloudflare_install_and_setup.sh
```

---

## 2) Confirm the tunnel is connected

In the logs you should see:
```
Registered tunnel connection connIndex=0 ... location=...
```
Four connections registered = healthy.

If not connected:
- Token expired or wrong → re-run the script (it re-fetches the token)
- Tunnel deleted in Cloudflare → script will recreate it
- Outbound firewall blocking port 7844 → allow `tcp/7844` outbound

---

## 3) SSH connection refused or timeout

The container uses `network_mode: host`, so `localhost:22` inside the container is the VM's port 22.

Check SSH is running on the VM:
```bash
sudo systemctl status ssh
```

Test locally:
```bash
ssh localhost
```

If SSH isn't running:
```bash
sudo systemctl enable --now ssh
```

---

## 4) Verify the generated config

```bash
cat config.generated.yml
```

Should show your SSH domain and `service: ssh://localhost:22`. If it shows `__SSH_DOMAIN__`, the script didn't generate the config correctly — re-run it.

---

## 5) DNS not resolving

Check the CNAME was created in Cloudflare Dashboard → your domain → DNS.
Should be a proxied CNAME pointing to `<tunnel-id>.cfargotunnel.com`.

If missing, re-run the script — it will attempt to create it again.

---

## 6) Mac can't connect

Make sure your Mac has the SSH config entry with the ProxyCommand:
```
Host ssh.your-domain.com
  User your-user
  ProxyCommand /usr/local/opt/cloudflared/bin/cloudflared access ssh --hostname %h
```

And cloudflared is installed on the Mac:
```bash
brew install cloudflared
```

---

## Quick checklist

- [ ] `cloudflared` container running (`docker ps`)
- [ ] Logs show 4 registered tunnel connections
- [ ] `config.generated.yml` has correct SSH domain
- [ ] DNS CNAME exists in Cloudflare dashboard
- [ ] SSH running on the VM (`systemctl status ssh`)
- [ ] Mac has correct `~/.ssh/config` entry with ProxyCommand
